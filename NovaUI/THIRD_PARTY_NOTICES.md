The theme-change license text comes from its upstream master LICENSE; the
2.0.2 npm archive omits a separate license file but marks the asset as MIT.

The daisyUI styles and themes were vendored at different versions; the versions
above reflect their existing headers. Preserve upstream notices when updating.
Python dependencies and container components carry their own licenses; consult
the installed distributions and the release security/license scan. This list
covers vendored browser files, not a complete container software bill of materials.
